# Rubik's Cube Site

Rubik's Cube Simulator and Solver made with three.js

Solver uses Old Pochman's method(used for blindfolded solving) as it was easiest to code. Gives a very long but correct solution. Can use keyboard for moving and playing with it as well.

## [Link to site](https://shash31.github.io/RubiksCube)
